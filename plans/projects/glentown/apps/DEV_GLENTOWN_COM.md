# dev.glentown.com — GlenTown Developer Portal

**Status:** PLANNED.

## Purpose

Canonical developer destination for GlenTown APIs and integrations.

## MVP

- API overview;
- authentication guidance;
- OpenAPI/reference documentation;
- request/response examples;
- errors, pagination, and rate-limit behavior;
- integration guides;
- changelog and deprecation notices;
- sandbox/test-environment guidance when available;
- security, contact, and reporting information.

## Later

- developer accounts and app registration;
- scoped integration access;
- webhook configuration;
- usage and limits dashboard;
- integration certification or approval where necessary.

## Relationship to API host

`api.glentown.com/` redirects human visitors here. The portal documents the API; it does not proxy authorization or replace API security.
