# app.glentown.com — GlenTown App Website

**Status:** PLANNED / implementation not established.

## Purpose

Public website specifically for GlenTown as a downloadable application: app-store/download paths, product features, screenshots, requirements, release information, privacy/support links and app-focused acquisition.

## Recommended architecture

Use an SEO-first web stack rather than defaulting to Flutter. Final stack requires an implementation decision after evaluating hosting, content workflow, analytics, structured data and reuse of GlenTown design tokens.

## MVP

- App overview/hero.
- Android download/store path; iOS path when available.
- Feature sections.
- screenshots/device previews.
- supported platforms/requirements.
- release/version information.
- privacy/terms/support links.
- FAQ links to `help.glentown.com`.
- canonical links into `glentown.com` for web use.

## Later

- release notes/changelog;
- Beta enrollment/waitlist if needed;
- referral/deep-link campaigns;
- localized acquisition pages.
