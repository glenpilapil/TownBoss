# GlenTown Documentation Compliance Protocol

**Status:** CANONICAL / MANDATORY

All substantial GlenTown development must follow the TownBoss documentation compliance cycle.

## Planning gate
Before work begins, read the relevant portfolio rules, GlenTown implementation plan, current state, decisions and rules, acceptance criteria, Memory, applicable app plans, and repository-local documentation for the code being changed.

## Execution gate
Re-check governing documents whenever scope, architecture, dependencies, risk, release criteria, or ownership assumptions materially change.

## Final review gate
Before reporting or checkpointing, re-read the governing documents and compare the actual result against the approved scope, decisions, architecture, acceptance criteria, validation evidence, and Memory requirements.

## Documentation Compliance Receipt
Each substantial final report must state:
- planning documents consulted;
- execution re-checks;
- final-review documents;
- conflicts found or NONE;
- approved exceptions or NONE;
- documents updated;
- Memory updated: YES/NO;
- implementation-plan dashboard updated: YES/NO.
