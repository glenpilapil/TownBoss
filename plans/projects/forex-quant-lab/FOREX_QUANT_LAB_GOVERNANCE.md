# Forex Quant Lab Governance Baseline

Status: CANONICAL / PROJECT-SPECIFIC

Forex Quant Lab inherits the TownBoss Development Rules and Project Governance Standard.

## Rules
- Research hypotheses and promotion criteria are defined before optimization.
- Data provenance and reproducibility are mandatory.
- Evaluation must include robustness and out-of-sample evidence before later-stage experiments.
- Strategy logic, risk controls, and execution responsibilities remain separated.
- Later-stage experiments require the approvals and limits defined by the implementation plan.
- Failed hypotheses remain in Memory.
- Material work updates the implementation dashboard and Memory.

## Acceptance baseline
- [ ] Research protocol approved.
- [ ] Data-quality and provenance gate passed.
- [ ] Backtest and robustness gate passed.
- [ ] Out-of-sample gate passed.
- [ ] Simulation gate passed.
- [ ] Risk controls verified.
- [ ] Any later-stage experiment is reviewed against predefined criteria.
- [ ] Continue, modify, or stop decision is recorded from evidence.

## Documentation compliance
Before substantial work, read the portfolio development rules, implementation plan, current state, this file, Memory, and repository-local research instructions. Re-check them when assumptions or stage criteria change. Final reports include a Documentation Compliance Receipt.
